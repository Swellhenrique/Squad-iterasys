# Automação de Testes Web — Iterasys

## 📌 Sobre o projeto

Projeto de automação de testes funcionais web desenvolvido com Python e Selenium WebDriver, tendo como alvo a plataforma de ensino Iterasys.

O objetivo é validar funcionalidades da aplicação por meio de scripts automatizados, aplicando conceitos de Quality Assurance (QA), planejamento de testes e critérios de aceitação.

**Site sob teste:** https://iterasys.learnworlds.com/

## 🎯 Objetivos

- Automatizar cenários de teste funcionais.
- Validar critérios de aceitação.
- Verificar o comportamento das funcionalidades da aplicação.
- Praticar a identificação de elementos e interação com páginas web.
- Aplicar boas práticas de organização e manutenção de scripts de automação.

## 🧪 Escopo da automação

Foram selecionadas quatro funcionalidades para automação:

| Funcionalidade | Objetivo |
|---|---|
| Contato | Validar o preenchimento e envio do formulário de contato. |
| Cursos | Validar a navegação e o acesso à área de cursos. |
| Login | Validar o acesso à tela de login e os comportamentos previstos no cenário. |

Os passos e resultados esperados são definidos conforme os casos de teste e critérios de aceitação do planejamento.

## 🛠️ Tecnologias utilizadas

- Python
- Selenium WebDriver
- Google Chrome
- Git e GitHub

## 📊 Planejamento de testes

- Casos de teste planejados: 6
- Critérios de aceitação planejados: 1
- Funcionalidades selecionadas para automação: 4

Os resultados da execução, a quantidade de scripts criados e o tempo investido serão atualizados conforme a conclusão das automações.
